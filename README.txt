fiches – Webversion für GitHub Pages

Inhalt:  index.html   die App
         packs/       die Wortschatz-Pakete (Französisch, Spanisch, Englisch)

Hochladen: alle Dateien und den Ordner "packs" in ein GitHub-Repository legen,
dann Settings → Pages → "Deploy from a branch", Branch "main", Ordner "/ (root)".
Für ein Update einfach die neue index.html bzw. die neuen Pakete hochladen (überschreiben).
